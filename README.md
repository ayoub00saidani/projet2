# Gestion des taches (Python)

Application console simple pour gerer des taches quotidiennes.
Projet de la matiere **Outils collaboratifs (Git / GitHub)** - Licence 1.

## Fonctionnalites

- **1 - Ajouter une tache** : saisie du titre (un titre vide est refuse)
- **2 - Afficher les taches** : liste numerotee, message si la liste est vide
- **3 - Rechercher une tache** : recherche par mot-cle dans le titre
- **0 - Quitter** : ferme le programme (toute autre option affiche une erreur)

## Etapes realisees

1. Creation du dossier du projet dans VS Code
2. Ecriture de `main.py` (menu, ajout, affichage, recherche)
3. Redaction du `README.md`
4. Initialisation de Git et creation des commits
5. Publication sur GitHub avec `git push`

## Execution

1. Ouvrir le dossier du projet dans VS Code
2. Ouvrir le fichier `main.py`
3. Cliquer sur le bouton **Run Python File** (triangle en haut a droite)
4. Utiliser le menu dans le terminal
