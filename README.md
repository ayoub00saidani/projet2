
# Gestion des taches (Python)

Application console simple pour gerer des taches quotidiennes.

Projet de la matiere **Outils collaboratifs (Git / GitHub)** - Licence 1.

## Fonctionnalites

- **1 - Ajouter une tache** : saisir un titre et refuser les titres vides.
- **2 - Afficher les taches** : afficher la liste numerotee des taches.
- **3 - Rechercher une tache** : rechercher une tache par mot-cle.
- **0 - Quitter** : fermer le programme.
- Afficher un message d'erreur pour un choix invalide.

## Technologies utilisees

- Python
- Git
- GitHub
- Visual Studio Code

## Organisation du projet

- `main.py` : contient le code de l'application.
- `README.md` : contient la description du projet et les instructions d'utilisation.

## Execution

1. Ouvrir le dossier du projet dans VS Code.
2. Ouvrir le fichier `main.py`.
3. Cliquer sur **Run Python File**.
4. Utiliser le menu dans le terminal.
